# vector_store/

Generated by `python -m app.embeddings.indexer` (see `app/embeddings/vector_store.py`).

| File | Contents |
|---|---|
| `embeddings.npy` | L2-normalized embedding matrix, one row per indexed chunk |
| `chunk_metadata.jsonl` | One JSON record per line: `{"chunk_id": ..., "metadata": <Chunk fields>}`, same row order as `embeddings.npy` |
| `index_state.json` | `{"provider", "model", "dimensions", "count"}` — used to detect provider/dimension mismatches on reload |

Git-ignored — regenerate locally with the indexer rather than committing it.
`backup/`, `metadata/`, `snapshots/` are reserved for future milestones
(not used yet).

See the [root README](../README.md) for indexer/retriever usage.
